# سلام، اینجا اکسپروناله 👋

اکسپرونال روی تهیه و ارائه **محتوای آماده فارسی** کار می‌کنه. در کنار محتوا، بعضی ابزارهای کاربردی مرتبط با نوشتن، بررسی و آماده‌سازی متن رو هم توسعه می‌دیم؛ چون خودمون هر روز با همین مسائل سروکار داریم.

بخشی از تجربه‌ها، تست‌ها و چیزهایی که فکر می‌کنیم برای بقیه هم مفید باشه، به‌مرور اینجا منتشر می‌کنیم.

## الان روی GitHub چه چیزهایی داریم؟

یکی از موضوع‌هایی که فعلاً دنبالش می‌کنیم، تحلیل متن فارسی و حالت‌هاییه که معمولاً در تست‌های ساده دیده نمی‌شن؛ چیزهایی مثل نیم‌فاصله، Unicode، ترکیب متن فارسی و انگلیسی، URL، ایمیل، اعداد فارسی و انگلیسی و انتقال متن از Word یا صفحات وب.

برای همین یک مخزن جدا برای نمونه‌ها و تست‌کیس‌های این موضوع ساختیم:

[Persian Text Analysis Tests](https://github.com/Expronal/persian-text-analysis-tests)

داخل این مخزن، نمونه‌های واقعی و Edge Caseهایی رو جمع می‌کنیم که می‌تونن برای تست ابزارهای تحلیل و پردازش متن فارسی به درد بخورن.

## کلمه‌شمار و تحلیلگر متن فارسی

وقتی با تعداد زیادی مقاله و محتوای فارسی سروکار داشته باشی، کارهایی مثل شمارش کلمات، بررسی ساختار تیترها، یکدست‌کردن اعداد یا آماده‌سازی متن قبل از انتشار خیلی زود به بخشی از کار روزانه تبدیل می‌شن.

یکی از ابزارهایی که در اکسپرونال برای همین کارها توسعه دادیم، [کلمه‌شمار و تحلیلگر متن فارسی اکسپرونال](https://expronal.ir/کلمه-شمار-آنلاین/) هست.

این ابزار در کنار شمارش کلمات و کاراکترها، اطلاعاتی مثل تعداد جمله‌ها، پاراگراف‌ها، خطوط، زمان تقریبی مطالعه، میانگین کلمات هر جمله و ساختار تیترهای H1، H2 و H3 رو هم نمایش می‌ده.

قابلیت‌هایی مثل تبدیل اعداد انگلیسی به فارسی و برعکس، تبدیل متن به حالت ساده و URL Encode/Decode هم داخل همون محیط در دسترس هستن.

## اکسپرونال دقیقاً چه کاری انجام می‌ده؟

بخش اصلی اکسپرونال به **محتوای آماده** مربوط می‌شه.

ایده اینه که برای بعضی موضوع‌ها لازم نباشه هر بار فرایند تولید محتوا از صفر شروع بشه و بشه از میان محتواهای آماده، گزینه مناسب رو پیدا و برای سایت استفاده کرد.

در کنار این بخش، ابزارهایی مثل کلمه‌شمار هم ساخته می‌شن تا بعضی از کارهای مرتبط با بررسی و آماده‌سازی محتوا ساده‌تر بشن.

این GitHub بیشتر جاییه برای انتشار تست‌ها، نمونه‌ها و تجربه‌های فنی مرتبط با همین ابزارها؛ نه صفحه فروش محتوا.
